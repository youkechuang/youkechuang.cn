BabyFeedSiri 奶宝：用 Siri 快速记录宝宝喂养和尿布

一个本地优先的 iOS 宝宝喂养与尿布记录 App 原型，目标是在最忙乱的照护场景里，让用户通过手动输入或 Siri 语音快速完成记录，并获得下一次喂奶提醒。

产品摘要 核心功能 Siri 入口 技术实现 后续路线

产品摘要

奶宝解决的是新手父母和家庭照护者的高频记录问题：喝奶多少、什么时候尿尿、什么时候便便、下一次大概什么时候喂奶。

目标用户新生儿和婴幼儿家庭照护者。
核心价值少打字、快记录、能提醒。
数据策略本地优先，记录保存在设备文档目录。

核心功能

  • 手动记录喝奶、尿尿、便便。
  • 根据最近一次喝奶预测下一次喂奶时间，默认按 3 小时间隔。
  • 根据最近记录粗略提示可能尿尿、便便时间。
  • 本地通知提醒下一次喂奶。
  • 数据保存在设备本地 Documents/baby-log.json。

Siri 和快捷指令

App 名称显示为“奶宝”，适合通过 Siri 或 Shortcuts 快速调用。

  • “用奶宝记录宝宝喝奶”
  • “用奶宝记录奶量”
  • “用奶宝喂奶”
  • “用奶宝记录宝宝尿尿”
  • “用奶宝记录宝宝便便”
  • “用奶宝查询宝宝状态”
  • “用奶宝看宝宝今天喝了多少奶”

当前 Siri 入口拆成独立 Intent：记录喝奶、记录尿尿、记录便便、查询宝宝状态。这样更适合语音交互，也降低误操作。

技术实现

App 技术栈SwiftUI + App Intents + 本地 JSON 存储。
核心文件BabyIntents.swift、BabyLogStore.swift、PredictionEngine.swift。
运行方式使用 XcodeGen 生成项目后，在 Xcode 中运行。
xcodegen generate
open BabyFeedSiri.xcodeproj

后续路线

  1. 补充母乳左右侧、奶粉 / 母乳类型。
  2. 加入夜间模式、锁屏小组件和更低打扰提醒。
  3. 用宝宝自己的历史间隔动态计算喂奶、尿布和排便预测。
  4. 增加每日 / 每周图表：总奶量、平均间隔、最长夜间睡眠。
  5. 支持 iCloud 同步，方便家人共同记录。
