1. 背景与问题

当前 Maphub 已经具备预习、闯关考试、每日挑战、错题复习和查看答案能力， 但预习模式仍然偏向“列表查询”，不够符合地图学习的直觉。

核心问题

用户进入预习后，应该首先和地图互动，而不是在右侧列表中查找省份。 预习模式需要从“展示资料”升级为“主动探索 + 分区记忆”。

  • 省份列表占用空间较大，用户容易把注意力放在列表而不是地图上。
  • 默认显示所有名称时学习难度过低，更像直接看答案。
  • 全国 34 个省级行政区一次学习负担较重，需要按区域拆分。
  • 预习和测试之间缺少“学完某个区域后立即测试该区域”的闭环。

2. 迭代目标

体验目标

让用户在预习模式下通过点击地图区域获取省份信息，形成更自然的探索体验。

学习目标

支持按华北、华东等区域分步预习和测试，降低一次性学习压力。

产品目标

将地图游戏从简单点击小游戏升级为可持续使用的地理学习工具。

运营目标

提高用户停留时间、重复访问概率和地图工具的独立访问价值。

4. 预习模式设计

预习模式的主交互从“看列表”调整为“点地图”。右侧区域从省份长列表改为学习控制面板。

默认状态

地图不显示省份名称，右侧提示“点击地图上的省份查看信息”。

点击省份

地图高亮当前省份，右侧显示省份全称、行政中心、区域和类型。

显示名称

用户打开“显示省份名称”后，地图出现省份标签，用于对照复习。

切换下一个

点击“上一个 / 下一个”后，按当前区域顺序切换学习对象并定位地图。

5. 区域学习与测试

区域是本次迭代的核心学习单位。相比一次性学习全国，区域学习更符合记忆节奏， 也更适合手机端短时间练习。

全部 华北 东北 华东 华中 华南 西南 西北
  • 预习模式选择区域后，只围绕当前区域进行上一个 / 下一个切换。
  • 地图上非当前区域可以降低视觉权重，但仍允许点击查看信息。
  • 考试模式选择区域后，题目只从该区域中抽取。
  • 每日挑战仍默认使用全国范围，保持每日挑战的完整性。

6. 用户流程

进入地图工具
选择预习学习
选择区域
点击地图省份
查看学习卡片
开始区域测试

该流程将“认识地图”和“考试验证”连接起来。用户不需要理解复杂规则，只需要按照地图点击和区域按钮操作即可。

8. 验收标准

  • 预习模式默认不显示省份名称。
  • 用户可以通过开关显示或隐藏省份名称。
  • 点击地图任意省份后，右侧能显示该省份的完整信息。
  • 当前选中的省份在地图上有明显高亮状态。
  • 选择华东、华北等区域后，学习对象按区域切换。
  • 区域测试只从所选区域出题。
  • 每日挑战和错题复习不被本次改动破坏。
  • 桌面端和手机端均无文字重叠、按钮溢出、横向滚动。

9. 风险与后续

主要风险

区域筛选和考试出题会影响现有闯关逻辑，需要重点验证题目数量、完成条件、错题记录和查看答案逻辑。

后续可以继续扩展：

  • 为每个省份增加更具体的记忆提示。
  • 增加“已掌握 / 需复习 / 未学习”的学习状态。
  • 增加区域学习进度，例如“华东已学习 5/7”。
  • 增加更适合儿童或新手的初级模式。
