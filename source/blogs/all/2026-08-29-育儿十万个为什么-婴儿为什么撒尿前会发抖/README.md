# 育儿十万个为什么（一）：婴儿为什么撒尿前会发抖

> 系列第 1 篇。专门收那些"看着吓人、其实正常"的娃。下一篇预告：娃为啥睡着了还突然乐一下。

有天半夜，娃腿一哆嗦，紧接着就是一泡尿。我差点没从床上弹起来——这是要烧了？要抽了？

结果就是普通的"尿前抖"。吓我的从来不是问题本身，是问题没来、我先把心放出去跑了一圈。

## 为什么抖

三句话讲完：

1. 娃的神经系统还在"毛坯装修"，排尿这套操作太费脑，手容易跟着一起抖。
2. 排尿会刺激交感神经——就是让你起鸡皮疙瘩、打冷颤的那根。娃比大人敏感，反应直接写脸上。
3. 有点凉。娃体温调节不行，一冷就更抖。

把暖气开好、把娃裹暖和点，抖基本就少了。反证它多半跟"冷 + 神经反射"有关，不是病。

## 啥时候去看医生

抖不可怕，抖 + 别的不对劲才可怕。碰上这些，别硬扛：

- 发烧、体温怪
- 哭个没完、精神蔫、奶吃得少、老想睡
- 尿尿时痛苦、抗拒，或者尿不出来、尿很少
- 尿很黄、发红、有怪味
- 抖得久、抖得频、跟尿尿也没关系

一句话：只抖、人好、吃喝拉撒都正常，多半没事；抖 + 别的不舒服，去看。

心里不踏实，体检顺带查个尿常规，便宜又安心。
