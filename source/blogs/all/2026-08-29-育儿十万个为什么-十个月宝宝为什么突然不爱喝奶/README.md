# 育儿十万个为什么（二）：十个月的宝宝为什么突然不爱喝奶

> 系列第 2 篇。上一篇讲娃为啥撒尿前先抖一下，这篇讲另一件让全家血压飙升的事：娃为啥突然不喝奶了。下一篇预告：娃为啥睡着了还突然乐一下。

家里一个十个月大的闺女，纯奶粉喂养。前阵子还好好的，每天该吃吃该喝喝，突然开始不喝奶了：奶嘴塞过去扭头，奶瓶放嘴边躲，喂急了直接哭。夫妻俩轮番上阵——爸爸喂、妈妈喂、换抱姿喂、换温度喂，全军覆没。

先说结论：十个月前后突然少喝奶，大多数是"正常的阶段性现象"，不是娃病了。但"正常"不等于不用管，得会分辨。

## 为啥突然不喝

十个月是个"什么都想干"的年纪，奶在她心里的排名开始往后掉。常见原因有这么几个，常常是好几样凑一块：

1. 注意力被抢走了。会爬会扶站，世界那么大，她哪还有心思坐着喝奶。喝到一半起来找东西玩，奶就断了。
2. 辅食开始有存在感。十个月已经能吃不少种类的食物，有点味道、有点嚼头的东西比奶香。奶从"主食"变成"补充"，量自然下来。
3. 出牙。这前后上下门牙陆续冒头，牙龈又痒又疼，吸吮会顶得牙肉难受，她就抗拒。
4. 吸奶太累。这个月龄一顿奶动辄一百多毫升，吸得腮帮子酸，她就用"不喝"来抗议。
5. 奶本身的问题。奶太凉或太烫、奶嘴孔太小吸得费劲、奶粉味道变了（换过批次/换过牌子），都可能让娃突然不买账。

还有一个容易被忽视的：娃在用不喝奶表达"我不想这时候喝"。十个月的娃已经有了自己的主意，"我说不行就是不行"。

## 怎么办

按性价比从高到低排：

- 固定喂奶的环境和流程。安静、没玩具、没电视、抱姿熟悉。娃的状态对了，喝得就多。
- 饿一点再喂。别把奶当解药、当哄睡工具，等她自己有点饿了再上。
- 换个大孔奶嘴。十个月的娃吞咽能力上来了，小孔吸着费劲，大孔省力。
- 奶温盯紧。手背内侧试一下，温温的，不烫不凉。
- 奶量降了就别追。总量掉个几十毫升不用慌，先把辅食的营养顶上来：奶制品、肉蛋、主食轮着吃，一天奶量守住 400 毫升以上基本就够。
- 出牙期的娃，喂之前给个牙胶咬一会儿，牙龈舒服了配合度会高一些。
- 实在不喝，换个工具试试：学饮杯、敞口杯、勺子舀。十个月已经可以开始练杯子了，一举两得。

## 啥时候去看医生

不爱喝奶不可怕，"不爱喝 + 不对劲"才可怕。碰上这些别硬扛：

- 一天奶量掉到 300 毫升以下，连续好几天，辅食也明显吃少
- 尿少（一天湿尿布少于 6 片）、口唇干、哭没眼泪——这是脱水信号
- 发烧、精神蔫、老想睡
- 口腔溃疡、鹅口疮（舌头两颊有擦不掉的白膜）
- 喝奶时痛苦、哭闹，或者吐奶、拉肚子
- 体重不增反降

一句话：吃得少但人精神、玩得欢、尿量正常，多半是阶段性的，调整喂法就行；精神差、尿量明显变少、体重掉，去看医生。

心里不踏实，体检时跟医生说一声，称个体重、看看口腔，几秒钟的事。
